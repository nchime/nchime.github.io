옆자리 개발자의 화면을 보고 "저 사람 뭔가 다르다"라고 느낀 적이 있을 겁니다. 마우스에 손을 거의 대지 않는데 창이 순식간에 나뉘고, 터미널 여러 개가 동시에 돌아가고, 손가락 몇 번에 다른 데스크톱으로 넘어가 검색을 마치고 돌아옵니다.

이건 재능이 아니라 **세팅과 습관**의 문제입니다. 이 글에서는 맥북을 기준으로 다섯 가지를 정리합니다.

1. 마우스 없이 단축키로 IDE(VS Code)와 브라우저(Chrome) 다루기
2. 터미널과 CLI 멀티뷰
3. 가상 데스크톱 (1번 화면은 개발, 2번 화면은 검색)
4. 빠른 화면 분할 (2분할, 4분할)
5. 클립보드 히스토리

> **표기법**: `⌘` Command, `⌥` Option, `⌃` Control, `⇧` Shift, `fn` Fn(🌐) 키

---

## 1. 마우스 없이 단축키로 일하기

목표는 마우스를 아예 안 쓰는 게 아닙니다. **손이 키보드 홈 포지션을 떠나는 횟수를 줄이는 것**입니다. 손을 마우스로 옮겼다가 돌아올 때마다 1~2초가 사라지고, 무엇보다 생각의 흐름이 끊깁니다.

### VS Code 필수 단축키 (macOS)

#### 탐색: 파일과 코드 사이 이동

| 단축키 | 기능 |
|:------|:-----|
| `⌘ P` | 파일 이름으로 빠르게 열기 (Quick Open) |
| `⌘ ⇧ P` | 명령 팔레트, 모든 기능의 입구 |
| `⌘ ⇧ O` | 현재 파일의 심볼(함수, 클래스)로 이동 |
| `⌘ T` | 워크스페이스 전체 심볼 검색 |
| `⌃ G` | 특정 줄 번호로 이동 |
| `F12` | 정의로 이동 |
| `⌥ F12` | 정의 미리보기 (Peek) |
| `⇧ F12` | 참조 찾기 |
| `⌃ -` / `⌃ ⇧ -` | 이전 / 다음 커서 위치로 돌아가기 |
| `⌃ Tab` | 최근 연 에디터 탭 전환 |
| `⌘ ⇧ [` / `⌘ ⇧ ]` | 이전 / 다음 탭 |

> `⌘ P` 창에서 `@`를 입력하면 심볼, `:`를 입력하면 줄 번호, `>`를 입력하면 명령 팔레트로 바뀝니다. 이 창 하나만 잘 써도 사이드바를 클릭할 일이 거의 없어집니다.

#### 편집: 멀티 커서와 줄 단위 조작

| 단축키 | 기능 |
|:------|:-----|
| `⌘ D` | 같은 단어를 하나씩 추가 선택 (멀티 커서) |
| `⌘ ⇧ L` | 같은 단어를 한 번에 전부 선택 |
| `⌥ ⌘ ↑` / `⌥ ⌘ ↓` | 위 / 아래 줄에 커서 추가 |
| `⌥ ↑` / `⌥ ↓` | 현재 줄을 위 / 아래로 이동 |
| `⇧ ⌥ ↑` / `⇧ ⌥ ↓` | 현재 줄을 위 / 아래로 복제 |
| `⌘ ⇧ K` | 현재 줄 삭제 |
| `⌘ Enter` / `⌘ ⇧ Enter` | 아래 / 위에 새 줄 삽입 (커서 위치와 상관없이) |
| `⌘ /` | 주석 토글 |
| `⌃ ⇧ ⌘ →` / `⌃ ⇧ ⌘ ←` | 선택 영역 확장 / 축소 |
| `⌘ L` | 현재 줄 선택 |
| `F2` | 심볼 이름 일괄 변경 (Rename) |
| `⌘ .` | Quick Fix (자동 import, 리팩터링 제안) |
| `⇧ ⌥ F` | 문서 포맷팅 |

#### 레이아웃: 패널과 사이드바

| 단축키 | 기능 |
|:------|:-----|
| `⌘ B` | 사이드바 토글 |
| `⌘ J` | 하단 패널 토글 |
| `` ⌃ ` `` | 통합 터미널 토글 |
| `` ⌃ ⇧ ` `` | 새 터미널 생성 |
| `⌘ \` | 에디터 분할 (터미널에 포커스가 있으면 터미널 분할) |
| `⌘ 1` / `⌘ 2` / `⌘ 3` | 분할된 에디터 그룹으로 포커스 이동 |
| `⌘ ⇧ E` | 파일 탐색기 |
| `⌘ ⇧ F` | 전체 파일 검색 |
| `⌃ ⇧ G` | 소스 컨트롤(Git) |
| `⌘ K Z` | Zen 모드 (집중 모드) |
| `⌘ W` / `⌘ ⇧ T` | 탭 닫기 / 닫은 탭 다시 열기 |

> 단축키가 기억나지 않으면 `⌘ K ⌘ S`로 단축키 설정 화면을 열어 검색하세요. 자주 쓰는 기능에 단축키가 없다면 이 화면에서 직접 지정할 수 있습니다.

### Chrome 필수 단축키 (macOS)

## 2. 터미널과 CLI 멀티뷰

간지의 핵심은 **한 화면에 여러 개의 터미널이 동시에 살아 있는 모습**입니다. 왼쪽에서 개발 서버가 돌고, 오른쪽 위에서 테스트가 watch 모드로 돌고, 오른쪽 아래에서 git 작업을 하는 식입니다.

### iTerm2 / Ghostty 분할 단축키

맥에서 가장 많이 쓰는 iTerm2와 요즘 뜨는 Ghostty는 분할 단축키가 거의 같습니다.

| 단축키 | 기능 |
|:------|:-----|
| `⌘ D` | 세로 분할 (좌우로 나누기) |
| `⌘ ⇧ D` | 가로 분할 (위아래로 나누기) |
| `⌘ ⌥ ←↑→↓` | 방향키로 분할 창 간 이동 |
| `⌘ [` / `⌘ ]` | 이전 / 다음 분할 창 |
| `⌘ ⇧ Enter` | 현재 분할 창 최대화 / 복원 (Zoom) |
| `⌘ W` | 현재 분할 창 닫기 |
| `⌘ T` / `⌘ 1~9` | 새 탭 / N번째 탭 이동 |

### tmux: 세션이 살아남는 멀티뷰

터미널 앱을 닫아도, SSH 연결이 끊겨도 작업이 그대로 남아 있게 하려면 tmux를 씁니다. 기본 Prefix는 `⌃ b`입니다.

| 단축키 | 기능 |
|:------|:-----|
| `⌃b %` | 세로 분할 |
| `⌃b "` | 가로 분할 |
| `⌃b 방향키` | 분할 창 이동 |
| `⌃b z` | 현재 창 최대화 / 복원 |
| `⌃b c` / `⌃b 0~9` | 새 윈도우 / N번째 윈도우 |
| `⌃b d` | 세션에서 빠져나오기 (백그라운드 유지) |
| `tmux a` | 마지막 세션에 다시 붙기 |

### 멀티뷰를 채워 줄 CLI 도구

분할 창에 무엇을 띄우느냐가 화면의 완성도를 결정합니다.

| 도구 | 용도 |
|:----|:----|
| `lazygit` | 터미널 Git UI, 스테이징·커밋·리베이스를 키보드로 |
| `btop` | CPU·메모리·프로세스 모니터링 대시보드 |
| `k9s` | Kubernetes 클러스터 관리 TUI |
| `lazydocker` | Docker 컨테이너·로그 관리 TUI |
| `fzf` | 파일·명령 기록 퍼지 검색 (`⌃ R`로 명령 기록 검색) |
| `zoxide` | 자주 가는 디렉터리로 `z 폴더명` 한 번에 이동 |
| `claude` | Claude Code, 터미널에서 AI 에이전트와 함께 개발 |

## 3. 가상 데스크톱: 화면마다 역할 정하기

창을 쌓아 놓고 `⌘ Tab`으로 찾아 헤매는 대신, **데스크톱마다 역할을 고정**합니다.

| 데스크톱 | 역할 | 배치 앱 |
|:-------|:----|:-------|
| 1번 | 개발 | VS Code, 터미널 |
| 2번 | 검색·문서 | Chrome (공식 문서, 검색, AI 채팅) |
| 3번 | 커뮤니케이션 | Slack, 메일, 캘린더 |
| 4번 | 기타 | 음악, 메모, 회의 |

### 세팅 방법

**1) 데스크톱 만들기**
`⌃ ↑`로 Mission Control을 열고 화면 위쪽의 `+`를 눌러 데스크톱을 4개까지 만듭니다. (이 단계만 마우스가 필요합니다.)

**2) 숫자 단축키 켜기**
`시스템 설정 → 키보드 → 키보드 단축키 → Mission Control`에서 **"데스크탑 1로 전환"** ~ **"데스크탑 4로 전환"**을 체크합니다. 이제 `⌃ 1`, `⌃ 2`로 바로 이동합니다.

**3) 순서 고정하기**
`시스템 설정 → 데스크탑 및 Dock`에서 **"가장 최근의 사용 내역에 따라 자동으로 Spaces 재정렬"**을 끕니다. 이걸 켜 두면 데스크톱 순서가 계속 바뀌어서 근육 기억이 쌓이지 않습니다.

**4) 앱을 데스크톱에 고정하기**
해당 데스크톱에서 Dock의 앱 아이콘을 우클릭한 뒤 `옵션 → 지정 위치: 이 데스크탑`을 선택합니다. 앱을 실행하면 항상 지정한 데스크톱에서 열립니다.

### 데스크톱 관련 단축키

| 단축키 | 기능 |
|:------|:-----|
| `⌃ 1` ~ `⌃ 4` | N번 데스크톱으로 바로 이동 (위 설정 필요) |
| `⌃ ←` / `⌃ →` | 이전 / 다음 데스크톱 |
| `⌃ ↑` | Mission Control (전체 창 보기) |
| `⌃ ↓` | 현재 앱의 창만 보기 (App Exposé) |
| `⌘ Tab` | 앱 전환 (해당 앱이 있는 데스크톱으로 자동 이동) |
| `` ⌘ ` `` | 같은 앱의 다른 창 전환 |
| `⌘ H` | 현재 앱 숨기기 |

> 트랙패드를 쓸 때는 세 손가락(또는 네 손가락)으로 좌우로 쓸어도 데스크톱이 전환됩니다. 하지만 `⌃ 1`, `⌃ 2`가 "몇 번 넘겨야 하지?" 고민할 필요가 없어 훨씬 빠릅니다.

## 4. 빠른 화면 분할: 2분할, 4분할

데스크톱 안에서는 창을 빠르게 배치해야 합니다. 에디터와 브라우저를 반반, 혹은 모니터를 네 칸으로 나눠 쓰는 일이 하루에도 수십 번 반복됩니다.

### macOS 기본 기능 (Sequoia 이상)

macOS 15 Sequoia부터 창 타일링이 기본으로 들어왔습니다. 창을 화면 가장자리로 끌어도 되지만, 단축키가 훨씬 빠릅니다.

| 단축키 | 기능 |
|:------|:-----|
| `fn ⌃ ←` / `fn ⌃ →` | 왼쪽 / 오른쪽 절반 |
| `fn ⌃ ↑` / `fn ⌃ ↓` | 위쪽 / 아래쪽 절반 |
| `fn ⌃ F` | 화면 채우기 |
| `fn ⌃ C` | 가운데 정렬 |
| `fn ⌃ R` | 원래 크기로 되돌리기 |

기본 기능은 4분할 단축키가 따로 없습니다. 4분할을 자주 쓴다면 다음 앱을 추천합니다.

### Rectangle: 무료 화면 분할 앱

[Rectangle](https://rectangleapp.com)은 무료 오픈소스 창 관리 앱입니다. `brew install --cask rectangle`로 설치합니다. 키 배치가 직관적이라 금방 손에 익습니다.

| 단축키 | 기능 |
|:------|:-----|
| `⌃ ⌥ ←` / `⌃ ⌥ →` | 왼쪽 / 오른쪽 절반 (2분할) |
| `⌃ ⌥ ↑` / `⌃ ⌥ ↓` | 위쪽 / 아래쪽 절반 |
| `⌃ ⌥ U` | 왼쪽 위 1/4 |
| `⌃ ⌥ I` | 오른쪽 위 1/4 |
| `⌃ ⌥ J` | 왼쪽 아래 1/4 |
| `⌃ ⌥ K` | 오른쪽 아래 1/4 |
| `⌃ ⌥ D` / `⌃ ⌥ F` / `⌃ ⌥ G` | 왼쪽 / 가운데 / 오른쪽 1/3 |
| `⌃ ⌥ E` / `⌃ ⌥ T` | 왼쪽 / 오른쪽 2/3 |
| `⌃ ⌥ Enter` | 최대화 |
| `⌃ ⌥ C` | 가운데 정렬 |
| `⌃ ⌥ Delete` | 원래 크기로 되돌리기 |
| `⌃ ⌥ ⌘ ←` / `⌃ ⌥ ⌘ →` | 창을 이전 / 다음 모니터로 이동 |

> 4분할 키 `U I J K`는 키보드 위에서 실제 화면 위치와 똑같이 배치되어 있습니다. U는 왼쪽 위, I는 오른쪽 위, J는 왼쪽 아래, K는 오른쪽 아래입니다. 한 번 이해하면 외울 필요가 없습니다.

> **한 단계 더**: 창을 수동으로 배치하는 것도 귀찮다면 [AeroSpace](https://github.com/nikitabobko/AeroSpace) 같은 타일링 윈도우 매니저가 있습니다. 창을 열기만 하면 자동으로 화면을 나눠 채우고, 데스크톱 전환까지 단축키로 관리합니다. 다만 익히는 데 시간이 걸리니 Rectangle에 익숙해진 다음 도전하세요.

## 5. 클립보드 히스토리: 한 단계 높은 복사/붙여넣기

기본 클립보드는 **마지막으로 복사한 하나**만 기억합니다. A를 복사해 붙여넣고, B를 복사해 붙여넣고, 다시 A가 필요해서 원래 위치로 돌아가는 일을 하루에 몇 번이나 반복하나요?

클립보드 히스토리 도구를 쓰면 **여러 개를 연속으로 복사해 두고, 필요할 때 골라서 붙여넣을 수 있습니다.**

### 도구 비교

| 도구 | 가격 | 기본 단축키 | 특징 |
|:----|:----|:----------|:----|
| [Raycast](https://www.raycast.com) | 무료 | 직접 지정 (보통 `⌘ ⇧ V`) | Spotlight 대체 런처, 클립보드·스니펫·창 관리까지 통합 |
| [Maccy](https://maccy.app) | 무료 (오픈소스) | `⌘ ⇧ C` | 가볍고 단순함, 검색 지원 |
| [Paste](https://pasteapp.io) | 유료 (구독) | `⌘ ⇧ V` | 화면 하단 카드형 UI, 기기 간 동기화 |
| macOS Spotlight (Tahoe 이상) | 기본 내장 | `⌘ Space` 후 `⌘ 4` | 별도 설치 없이 클립보드 기록 확인 |

개인적으로는 **Raycast**를 추천합니다. 클립보드 히스토리 외에도 앱 실행, 창 분할, 스니펫, 계산기를 하나의 단축키로 처리할 수 있어서 키보드 중심 작업과 잘 맞습니다.

### 이렇게 쓰면 달라진다

**1) 몰아서 복사하고, 몰아서 붙여넣기**
API 문서에서 엔드포인트 URL, 헤더 이름, 예제 JSON을 연달아 `⌘ C` 해 둡니다. 에디터로 돌아와서 클립보드 히스토리를 열고 하나씩 골라 붙여넣습니다. 브라우저와 에디터를 왕복하는 횟수가 1번으로 줄어듭니다.

**2) 자주 쓰는 문구는 고정(Pin)**
테스트 계정 이메일, 사내 서버 주소, 자주 쓰는 커밋 메시지 접두어처럼 반복해서 입력하는 문자열은 고정해 둡니다. Raycast는 `⌘ ⇧ P`로 항목을 고정할 수 있습니다.

**3) 검색으로 찾기**
"아까 복사한 그 에러 메시지"를 찾을 때 히스토리 창에서 키워드 몇 글자만 입력하면 바로 찾아집니다.

**4) 서식 없이 붙여넣기**
웹에서 복사한 글을 문서나 메일에 붙일 때 `⌥ ⇧ ⌘ V`를 누르면 글꼴과 색상 없이 텍스트만 붙습니다. (macOS 기본 기능)

> **보안 주의**: 클립보드 히스토리는 비밀번호나 API 키도 그대로 저장합니다. 1Password 같은 비밀번호 관리자 앱은 제외 목록에 넣고, 보관 기간을 7일 정도로 짧게 설정하세요. Raycast와 Maccy 모두 앱 단위 제외 설정을 지원합니다.

> VS Code에서는 `⌘ ⇧ V`가 마크다운 미리보기 단축키와 겹칩니다. 클립보드 히스토리 단축키를 `⌘ ⇧ V`로 지정했다면 VS Code의 마크다운 미리보기는 다른 키로 바꾸는 것이 좋습니다.
