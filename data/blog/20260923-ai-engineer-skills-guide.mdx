AI 엔지니어는 ML 엔지니어와 다릅니다. 모델을 직접 학습시키는 것이 아니라 이미 존재하는 Foundation Model(LLM, 임베딩 모델 등)을 활용해 실제 비즈니스 문제를 해결하는 애플리케이션을 만드는 역할입니다.

---

## 1. AI 엔지니어 vs 유사 직군

| 구분 | 핵심 업무 | 주요 도구 |
|:-----|:---------|:---------|
| ML 엔지니어 | 모델 학습(Training) - 데이터셋 준비, 하이퍼파라미터 튜닝 | PyTorch, TensorFlow |
| AI 엔지니어 | 모델 활용(Inference) - 프롬프트 설계, RAG 구축, 에이전트 개발 | OpenAI/Claude API, LangChain |
| 백엔드 개발자 | 결정론적 시스템 - 같은 입력에 같은 출력 | Spring, FastAPI |

AI 엔지니어는 확률적(Probabilistic) 시스템을 다룹니다. 같은 입력에도 다른 출력이 나올 수 있으며, 이를 제어하고 평가하는 역량이 필요합니다.

---

## 2. 필수 기술 역량 한눈에 보기

### 프로그래밍

| 언어 | 필요 수준 | 활용처 |
|:-----|:---------|:------|
| Python (필수) | 비동기(asyncio), 타입 힌팅(Pydantic), 테스트(pytest) | LLM API 호출, 데이터 처리 |
| TypeScript | Vercel AI SDK, LangChain.js | 풀스택 AI 앱 |
| SQL | pgvector 활용 벡터 검색 | 메타데이터 필터링, 로그 분석 |

### LLM 핵심 기술

| 영역 | 핵심 역량 |
|:-----|:---------|
| 프롬프트 엔지니어링 | System Prompt 설계, Few-shot 구성, Chain-of-Thought, Structured Output |
| RAG | 문서 청킹, 임베딩(OpenAI/Cohere/BGE), 벡터 DB(Pinecone/Qdrant/pgvector), 하이브리드 검색, 리랭킹 |
| AI 에이전트 | Tool/Function 설계, 루프 제어(Max Iteration/Timeout), 메모리 관리, 멀티 에이전트 |

### 인프라 및 운영

| 영역 | 핵심 역량 |
|:-----|:---------|
| LLMOps | 모니터링(레이턴시/토큰/에러율), 평가 파이프라인, A/B 테스트, 비용 관리 |
| 클라우드 | Docker/K8s, 서버리스(Lambda), GPU 인프라(vLLM), 캐싱 |
| 보안 | 프롬프트 인젝션 방어, PII 마스킹, API 키 관리, Rate Limiting |

## 3. AI/ML 기초 이론

직접 모델을 학습시키지 않더라도 알아야 할 기초 지식입니다.

| 영역 | 알아야 할 것 |
|:-----|:------------|
| 트랜스포머 | 어텐션 메커니즘, 토크나이제이션, 컨텍스트 윈도우, Temperature/Top-p |
| 임베딩 | 코사인 유사도, 차원의 저주, 범용 vs 도메인 특화 모델 |
| 평가 지표 | RAG 평가(Precision/Recall/NDCG), LLM-as-Judge |

---

## 4. 소프트 스킬

기술만으로는 AI 엔지니어가 될 수 없습니다.

| 역량 | 설명 |
|:-----|:----|
| 문제 정의 | 비즈니스 문제를 기술 요구사항으로 번역, AI 적합 여부 판단, MVP 범위 설정 |
| 트레이드오프 설명 | "정확도↑ = 비용 3배↑", "RAG 적용 = 검색 품질 의존" 등 의사결정 근거 제시 |
| 불확실성 관리 | "모르겠다"고 말하는 시스템 설계, 폴백 전략, 피드백 루프 구축 |

## 5. 경력별 준비 전략

| 경력 | 목표 | 준비 방법 |
|:----|:----|:---------|
| 신입~3년차 | 기초 역량 | Python 심화, LLM API 프로젝트(챗봇/요약기), RAG 튜토리얼, GitHub 포트폴리오 2~3개 |
| 4~6년차 | 실무 역량 | AI 도입 프로젝트 주도, 비용/레이턴시 최적화, 평가 시스템 구축, 장애 대응 경험 |
| 7년차+ | 아키텍처/리더십 | AI 전략 수립, 팀 구성, 벤더 평가(OpenAI vs Anthropic vs 오픈소스), 규제 대응 |

### 학습 로드맵

| 단계 | 목표 | 핵심 학습 |
|:----|:----|:---------|
| 1단계 | LLM API 활용 | OpenAI/Claude API 기본, 프롬프트 엔지니어링, Streamlit/Gradio UI |
| 2단계 | RAG 구축 | 문서 파싱/청킹, 임베딩, 벡터 DB, 하이브리드 검색 |
| 3단계 | 에이전트 개발 | Function Calling, LangGraph/CrewAI, 에이전트 제어 |
| 4단계 | 프로덕션 운영 | 모니터링/로깅, 평가 시스템, 비용 최적화 |

## 6. 국내 채용 현황 및 FAQ

### 채용 공고 요구 역량 (2026년 기준)

| 역량 | 언급 비율 | 비고 |
|:----|:---------|:----|
| Python | 95% | 거의 모든 공고에서 필수 |
| LLM API 경험 | 80% | OpenAI, Claude, Gemini |
| RAG 구축 | 60% | 벡터 DB, 임베딩 |
| 에이전트 개발 | 40% | 비교적 새로운 요구 |
| MLOps | 30% | 시니어 포지션 |

주요 채용 기업: 뤼튼, 업스테이지, 튜닙, 래블업(AI 스타트업) / 네이버, 카카오, 라인, 쿠팡(빅테크)

### 자주 묻는 질문

| 질문 | 답변 |
|:----|:----|
| AI 전공 필수? | 아님. 백엔드 경험 + LLM API/RAG 학습으로 전환 가능 |
| 수학 지식? | 벡터 연산, 코사인 유사도 정도면 충분 |
| 추천 프레임워크? | LangChain → LlamaIndex → SDK 직접 사용 → LangGraph |
| GPU 필수? | 아님. 클라우드 API 활용이 주력, 로컬 서빙 시에만 필요 |
| 영어? | 기술 문서 독해 수준이면 충분 |

## 마무리

AI 엔지니어의 핵심은 결국 "문제 해결"입니다. 가장 중요한 것은 직접 만들어보는 것입니다. 튜토리얼을 넘어 실제 문제를 AI로 풀어보세요.

기초 역량이 탄탄하면 새로운 기술에도 빠르게 적응할 수 있습니다. Python 실력, 시스템 설계 능력, 문제 정의 능력. 이 세 가지를 먼저 갖추고, 그 위에 AI 특화 스킬을 쌓아가세요.
